Dice Roller

Application Android permettant de lancer un dé à 6 faces.

Description

L'utilisateur appuie sur le bouton Roll pour lancer le dé.
Un nombre aléatoire entre 1 et 6 est généré et l'image correspondante est affichée.

Technologies
Kotlin
Jetpack Compose
Android Studio
Objectif

Projet réalisé pour apprendre les bases du développement Android avec Kotlin et Jetpack Compose.
